# LOG_DOSEN: Tragedi Dua Jari vs Keagungan Sepuluh Jari

Lu perhatiin gak pas lu ngetik panik kek kesurupan setrum bunyinya cuma `jdsajdjdjdsad...`? Itu adalah batasan fisik mutlak kalau lu cuma mengandalkan Two-Finger Pecking Style (Gaya ngetik andalan dua telunjuk). Kecepatan maksimal lu bakal *stuck* di situ-situ aja karena dua jari lu harus lompat-lompat keliling area keyboard seluas itu. Capek, lemot, dan rawan typo parah!

Di dunia pro coding dan hacking, lu wajib bermutasi ke 10-Finger Touch Typing. Konsep dasarnya adalah membagi rata beban kerja ke semua jari lu secara adil sosial tanpa perlu ngeliat keyboard sama sekali. Mata lu fokus ke layar monitor, jari lu otomatis gerak pake Muscle Memory (memori otot).

Jari telunjuk kanan-kiri pontang-panting kerja rodi. Kecepatan mentok di 30 WPM. Output tulisan acak-acakan kayak kucing jalan di atas keyboard.

Setiap jari punya wilayah jajahan tetap (Home Row: ASDF - JKL;). Kecepatan bisa tembus 100+ WPM! Ngetik kode sepanjang apa pun beres dalam hitungan detik.
